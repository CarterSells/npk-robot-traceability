# Outreach message drafts

Status: Stage 1 drafts, prepared 2026-09-26. Nothing has been sent. These templates do not authorize sending messages.

Authority: [build.md](../build.md), sections 2 and 5. Use with the [discovery guide](customer-discovery.md) and [private tracker template](private-tracker-template.md). The product is planned; no working integrations, customer results, or hosted access are claimed.

## Before using a draft

Select a relevant manipulation engineer or a credible introducer. Replace every bracketed placeholder with truthful details, use an actual sender identity and reply route, and confirm authorization to contact the recipient. Do not invent a prior meeting, relationship, customer, testimonial, scheduling link, or useful attachment. Keep recipient details and sent-message history in a private copy outside this repository.

The primary ask is a twenty-minute discussion of a recent regression, not a broad product pitch. Offer manual help mapping the incident only if the team can actually provide it. Do not request sensitive raw artifacts.

We'd appreciate a short introduction. We can help map one recent incident and share the resulting change-history template.

Thanks,
[actual sender name]

## First follow-up

Use approximately five business days after the initial message if there is no reply. Adapt the wording to the original request without inventing engagement.

Hi [introducer name],

Following up on the introduction request below. If someone comes to mind who owns manipulation testing, we'd appreciate a connection.

Thanks,
[actual sender name]

## Final follow-up

Use once the following week if there is still no reply, then stop unless they engage. Use this version only when a useful, shareable template actually exists; a local repository path is not a recipient-accessible link.

Hi [recipient name],

One last note: [accessible link to an actual useful template]. If a recent regression would be useful to map, we'd be glad to help.

Thanks,
[actual sender name]

## Logging and limits

After an authorized send, record its date, channel, response, and next action in the private tracker. Honor a decline or request to stop immediately. The two follow-ups are a maximum unanswered sequence, not a reason to ignore a recipient's wishes. A reply is not a commitment to a pilot; record only the next step they actually agreed to.

Founder identities, contact details, prospects, kickoff date, and sending authorization remain unspecified. These placeholders are intentional drafting fields, not launch-ready contact information.
